### mcPHASES (PhysioNet) — local only; source of truth for the released prior

| Field | Value |
| --- | --- |
| Name | mcPHASES: menstrual cycle physiological, hormonal, and self-reported events |
| Source | [PhysioNet](https://physionet.org/content/mcphases/1.0.0/) (version 1.0.0, 2025) |
| License | PhysioNet Restricted Health Data License 1.5.0 (restricted access; DUA required) |
| Access | Registered PhysioNet users who sign the agreement. Local copy (if present): `training/dataset-do-not-commit/hormones_and_selfreport.csv` or `$OPENCICLO_MCPHASES_CSV`. **Gitignored.** |
| Population | 42 consenting Canadian young-adult menstruators; recruitment via advocacy groups in the Greater Toronto Area; no recent hormonal contraception or diabetes by eligibility |
| Users / cycles | 42 people; two ~3-month intervals (subset returned for a second interval) |
| Variables | This OpenCiclo release uses **period timing only**: `phase == Menstrual` onsets. Hormones and symptoms are not used in the V0.1 predictor. |
| Missing data | Nearly daily rows; a few day-index gaps. Missing days of 1 are not treated as a new period. |
| Known biases | Small n; young adults; Canada / urban recruitment; wearable and CGM users; exclusion of recent hormonal contraception |
| Preprocessing | `openciclo.data.mcphases`: group by `(id, study_interval)`; period start = first day of each Menstrual run; map `day_in_study` to dates via a documented epoch. Do **not** concatenate 2022 and 2024 for the same person. |
| Limitations | Cannot support worldwide accuracy claims. The published `released_model.json` holds **aggregate** parameters only. |
| Redistribution | **No** (restricted health data). Do not commit the CSV. Aggregate release JSON is allowed. |

Related publication: open-access paper describing the resource (check that paper’s CC license separately from the **data** license). Data and paper licenses are not the same thing.

### Creighton Model / University of Utah cycle lengths — local only

| Field | Value |
| --- | --- |
| Name | Menstrual Cycles Length of Women in the USA and Canada, 1990–2013 |
| Source | Najmabadi / Stanford et al., University of Utah Hive ([doi:10.7278/S50d-4gxs-s4hj](https://doi.org/10.7278/S50d-4gxs-s4hj)) |
| Access | Local copy (if present): `training/dataset-do-not-commit/CrMcyclelength_share.csv` or `$OPENCICLO_CREIGHTON_CSV`. **Gitignored.** |
| Population | 581 heterosexually active women 18–40 with no known subfertility; Creighton Model FertilityCare charting in US/Canada centres; follow-up up to ~1 year |
| Users / cycles | File: 581 people, 3324 charted cycles. OpenCiclo walk-forward: 497 people with ≥2 consecutive starts, 587 contiguous runs, 2557 completed lengths. Conception cycles contribute a start (they close the previous cycle) but no following length. Missing `cycle_number` values start a new run. |
| Variables | `new_id`, `age`, `cycle_number`, `cycle_start_date`, `cycle_end_date`, `cycle_length`, `conception_cycle` |
| Known biases | Fertility-awareness users; trying to conceive / NFP context; 1990–2013; not a general app population |
| Preprocessing | `openciclo.data.creighton`: parse `M/D/YY` starts; split a person when `cycle_number` is not consecutive (missing charts are not one long cycle); skip runs with fewer than two starts |
| Redistribution | Do not commit the CSV. Aggregate metrics only. |

## Bias checklist (any future real dataset)

Document, at least:

- geography and language
- socioeconomic / device access
- age
- contraception and exogenous hormones
- regular vs irregular cycles
- self-report and skipped-log artifacts
- who is missing entirely (people who never use tracking apps)

Do not claim global accuracy unless evaluation data justify it.

## How OpenCiclo will ingest data later

Scripts under `training/preprocess/` should:

1. Check license/DUA
2. Write a dataset version hash into experiment configs
3. Emit only derived tables the license allows
4. Never require those files to import the `openciclo` forecasting package
